# LeetCode Challenges

This repository is a daily practice space for solving LeetCode problems consistently. The goal is to complete 3 or 4 problems per day, focusing on building problem solving habits, improving speed, and strengthening algorithmic thinking.


## Daily Goal

Aim for:

- 2 easy problems
- 1 medium problem
- 1 optional medium or hard problem
- it can be 4 or 5 or more it depends on my mood hahaha

Or any balanced mix depending on the topic and difficulty.

## Repository Structure

```text
leetcode-challenges/
├── challenges/
│   ├── easy/
│   ├── medium/
│   ├── hard/
│   └── twosum/
├── images/
├── readme.md

```

Each problem is stored in its own folder with a solution file and related notes when needed.

## Suggested Daily Routine

1. Solve 1 easy problem to warm up.
2. Solve 1 medium problem to build logic and structure.
3. Solve 1 more medium or easy problem for repetition.
4. If energy is good, complete 1 harder problem for challenge.
5. Review the solution, note time complexity, and improve if needed.

## Practice Format

For each problem, try to include:

- problem name
- difficulty
- approach/intuition
- algorithm used
- time complexity
- space complexity
- final code solution
